Geotechnical finite element analysis for AI agents

Ground models an agent builds and an engineer checks

Tellus 2D and Tellus3D are plane-strain and three-dimensional FE programs for soil, written in Rust. An AI agent drives them through Model Context Protocol tools: it builds the soil profile, structures and construction stages, calculates, reads results and writes the report. The engineer opens the same project in the desktop app and checks every step.

Two programs, one way of working

Plane strain for everyday design, 3D where the geometry demands it

Both programs share the soil models, the agent tools and the project-file approach, so a model that starts as a section can grow into a three-dimensional analysis with the same parameters.

Tellus 2D

plane strain
Elements
15-node cubic-strain triangles, or structured 25-node rectangles
Soil models
Linear elastic, Mohr–Coulomb (drained, undrained A, B, C), Hardening Soil and HS small, Soft Soil and Soft Soil Creep, hypoplastic sand
Structures
Elastic and elastoplastic plates with interfaces, geogrids, embedded piles, spring supports for struts and anchors
Analyses
K0 or gravity loading, staged construction, Biot consolidation, steady flow, vacuum preloading, φ–c reduction
Agent
33 MCP tools via tellus --mcp; chat panel in English or Thai
Runs on
macOS and Windows builds, 37 MB download, 73 MB idle; GPU solver on a cloud box

Tellus3D

three-dimensional
Elements
10-node tetrahedra; meshes follow layer surfaces interpolated between boreholes
Soil models
Linear elastic, Mohr–Coulomb, Hardening Soil and HS small, Soft Soil and Soft Soil Creep, drained or undrained
Structures
Shell plates with interfaces, embedded piles, TBM tunnels dug ring by ring with face pressure, shield, grout and lining
Analyses
Staged construction, coupled consolidation, PVDs and vacuum, φ–c reduction, measured pore pressure profiles
Agent
30 MCP tools via tellus3d --mcp, or over HTTP from a GPU server

Desktop app on this computer; tellus3d-server with cuDSS on an NVIDIA GPU

Agent workflow

The agent does the modelling, the engineer keeps the judgement

Every model edit is an undoable step on a project file the engineer can open. The agent reports only the numbers the tools returned, and writes its assumptions and limits into the report.

  1. Set the problemDescribe the site, the structure and the code check in words, a sketch or a borehole log.engineer
  2. Build the modelSoil layers, materials, plates, piles, tunnels and phases through typed MCP tools.agent
  3. CalculateOn this computer, or on a rented GPU that one command starts and stops.solver
  4. ReportDeformed meshes, contours and a PDF report with the model, phases and notes.agent
  5. Check and decideOpen the same project, inspect the results and correct anything that is wrong.engineer

Tellus3D

Build from source with Cargo; the app, the solver, the headless server and the TigrimOS agent build from one workspace. One script rents a cloud GPU, starts the compute server and points the app at it.

cargo build --release
target/release/tellus3d --mcp            # MCP on stdin/stdout
cloud/vast_gpu.sh up                     # rent a GPU, start the server
cloud/vast_gpu.sh down                   # destroy the box

The source is available on request from tellusfem@gmail.com. The formulation and benchmarks are in the Tellus3D paper on Zenodo.
